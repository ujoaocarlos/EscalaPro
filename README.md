# EscalaPro Essencial

Simulador gerencial de jornadas, dimensionamento de equipe e custos de pessoal.

## Uso

Abra `index.html` em um navegador moderno, preferencialmente por HTTPS. Os dados de cenários e rascunhos ficam somente no armazenamento local do navegador. Nesta versão, todos os recursos — salvar, imprimir, exportar CSV e copiar resumo — estão liberados sem chave.

## Limites do simulador

Os resultados são estimativas gerenciais. Eles não substituem folha de pagamento, orientação contábil, parecer jurídico, CCT ou análise de regras específicas da categoria.

## Publicação com GitHub Pages

No repositório, acesse **Settings → Pages**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`. O GitHub publicará este `index.html` como um site estático.
